# Decisions

One record for each decision, `NNNN-title-with-dashes.md`, with the next free number. A record has its title,
`# NNNN. Title`, its status and its date, then four sections: Context, Decision, Rejected alternatives and
Consequences. It is at most 400 words.

- A record is the maintainer's decision: none is added or changed unless the maintainer asked for it.
- Records 0001 to 0006 describe the implementation on `main`, and say so at their head.
- A document cites a record as `ADR NNNN`, with a link to its file.
